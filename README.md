
# ShopMind🛍️

An LLM-powered autonomous multi-agent shopping assistant.

## Project 📁

ShopMind uses multiple specialised AI agents
coordinated by a LangGraph supervisor to
autonomously research, compare and recommend
products.

## Planned Features

- Multi-agent AI architecture
- LangGraph orchestration
- Retrieval-Augmented Generation (RAG)
- Model Context Protocol (MCP)
- LLM Gateway using LiteLLM
- Advanced AI guardrails
- Recommendation engine
- AI evaluation and LLMOps
- Docker and CI/CD deployment

## Technology Stack

- Python
- FastAPI
- LangGraph
- LiteLLM
- Qdrant
- PostgreSQL
- Redis
- React / Next.js
- Docker
